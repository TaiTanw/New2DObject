# 01 — 预测接触设计收缩

> 整理自架构复盘与后续讨论、开发日志草稿。  
> 目的：冻结「什么和旧时序相同、什么才是新价值」。  
> 上级目录：[README.md](./README.md)

---

## 1. 一句话结论

**「施力导致的速度入账放在下一帧」——与旧方案时序同类，这不是白做。**  
预测接触的主收益是：**本帧用成对预测重叠写位移偏置（防穿/挤出）+ 接触对语义/职能分离**；速度晚一帧是**有意简化**，不是目标本身。

若只做「自定义结构初筛碰撞，仍整轴截断、无偏置、无成对解」，才会变成兜兜转转。

**静墙不进本预测 AABB 世界**（见 [03-静态墙与预测世界边界.md](./03-静态墙与预测世界边界.md)）。

## 2. 旧 vs 新：时序对照

| | 旧（相位 4/5 边沿） | 新（预测接触 + 管理器） |
|---|---|---|
| 接触依据 | 帧初几何 + 速度方向 → `nowWall` | 双方 `v_pre` 预测形状 → **接触对**（可推体） |
| 本帧对自己 | 常 `wordDelta.x = 0`（静墙式硬挡） | **`displacementBias` 挤出/分摊** |
| 对对方施力 | 位移后边沿 `AddForce`，下帧速度相才吃到 | 接触对解析后写意图，**下帧速度相入账**（刻意） |
| 数据完整性 | 单边命中，缺双方相对嵌入 | 预测世界算重叠 + 质量/环境影响权重 |
| 多体 | 实体本地相位 5，序相关 | 管理器统一 pair，可分帧传一跳 |

### 2.1 「是不是又变回原先时序了？」

- **仅就「推力 → 对方正式速度」**：是，都是 **T 帧判定意图，T+1 帧速度积分**。  
- **就「本帧会不会粘死/穿模/双边不公」**：否。旧方案缺本帧偏置与成对约束。

### 2.2 「是不是花了自定义结构只做初筛，效果差不多？」

- **若验收只看「箱子是否下一帧才加速」**：观感会像旧方案。  
- **若验收看「是否按嵌入挤出、静墙/可推分流、多箱可扩展」**：不一样。

**判定标准：** 本帧 Move 是否使用了由接触对算出的 `displacementBias`？  
- 是 → 预测世界有实质价值。  
- 否 → 仅初筛，接近白做。

### 2.3 刻意 T+1 应用「实体间施力 → 速度」的原因

范围：可推体之间的施力 → 正式速度入账（如 `secondaryPressure`，下帧相位 3 积分）。  
**不包括** 本帧 `displacementBias`。

| # | 原因 | 说明 |
|---|---|---|
| 1 | **预测重叠 ≠ 真实重叠（手感/语义）** | 若预测阶段就把实体间施力写入本帧正式速度，等于未撞先加速。T+1：先完成本帧位移（可带 bias），再按下帧「接触后动力学」积分。 |
| 2 | **管线可读性** | 「速度 → 预测 → 再写回速度 → 位移」调试更绕；意图进缓冲、下帧统一进速度相更清晰。 |
| 3 | **预测与实位移偏差 → 反向力与递归（主技术理由）** | bias/裁剪后落点可与预测不一致。同帧按预测施力可能错力；再喂回预测会 **预测→施力→改速度→再预测** 纠缠。T+1 = 每帧至多一跳。 |

关系：1 语义；3 系统；2 工程。  
与旧方案下帧吃力**动机不同**：旧是边沿挂力附带结果；新是已有本帧 bias 下的有界传播。

## 3. 预测物理世界（轻量）冻结范围

### 3.1 要做

```text
真实世界：当前 Collider（上帧 Move 后）
预测世界：pos + v_pre*dt 后的形状快照（自管 AABB；不必 PhysicsScene2D）
范围：可推 / 需成对挤出的运动体（不含静态墙，见 03）
接触对：预测形状重叠 → pair(normal, depth, kind)
本帧：displacementBias（权重挤出）
下帧：施力 / 速度修正入账
```

### 3.2 不做

- 完整 `PhysicsScene2D` 第二世界  
- 同帧力 → 再预测 → 再力无限递归  
- 斜坡/旋转预测（后置）  
- 旧相位 5 推箱路径与新路径长期双轨  
- 静态墙进 AABB 预测 pair 世界  

### 3.3 数据结构（自研薄层）

```text
PredictedMotionSample  // 实体上报
ContactPair            // 管理器生成（去重 A-B）
ContactSolverMgr       // 新相位：BuildPairs → Resolve → 写回
```

Unity **无**现成「运动学预测接触对 + Solver」玩法结构；Cast 只是输入之一。

## 4. 预测世界除时序外的作用

### 4.1 嵌入分档

| 模式 | 条件（示例） | 行为 |
|---|---|---|
| 贴着推 | 相对接近速度小 / 不施力 | 主要靠本帧 bias 挤出 |
| 推开/撞飞 | 相对速度大 | 下帧施力；bias 仍防穿 |

### 4.2 推动职能可退化

推箱不必长期保存「我对谁施力」；用 pair/重叠推导「正在推」供动画。  
环境力（冰面）仍可保留 Enter/Exit 引用容器。  
平台 `Delta` ≠ 推挤 `bias`。

### 4.3 几何感知 vs 预测接触

| 通道 | 含义 | 谁读 |
|---|---|---|
| 几何（相位 1） | 世界里「现在」有什么 | FSM、未来 AI |
| 预测接触（速度后） | 按 `v_pre` 会挤谁、多深 | 仅可推约束 / 防穿 |

混用风险：AI/FSM 把可推箱当墙滑墙、行为误切。

## 5. 挤出权重（总公式）

```text
weight_i = envImpact_i
bias_i   ∝  weight_i / (weight_a + weight_b) * separationVector
```

细节与多层算法见 [02-多层位移挤出.md](./02-多层位移挤出.md)。

## 6. 推荐帧管线（冻结）

```text
1 GeometricQuery      真实世界感知（含静墙）；AI/FSM 可用
2 PhyFunUpdate        环境 Enter/Exit（冰面等）
3 SpeedCalculation    环境+主动 → v_pre
   PositionPrediction 可推体上报 PredictedMotionSample
3.5 ContactSolverMgr  仅可推体预测重叠 → pairs
                      写 displacementBias（本帧）
                      写施力/速度意图（下帧）
4 Displacement        v_pre*dt + bias + 平台 Delta
                      + 静墙法向裁剪（相位1信息，非 AABB pair）
（旧 SecondOrder 推箱路径：迁移后删除）
```

- **本帧必须有（可推）：** bias  
- **可下帧（可推）：** 实体间速度施力（§2.3）  
- **静墙：** 不经 3.5 AABB pair；见文档 03
