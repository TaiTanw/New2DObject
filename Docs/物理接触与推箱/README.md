## 阅读顺序（建议）

1. `01` — 先建立「本帧 bias / 下帧动态力速度」总图
2. `03` — 明确静墙不进预测世界，避免范围膨胀  
3. `02` — 多层可推体只做挤出时的算法约定  
4. `04` — 实体接触 **速度施力** 与现码数据结构  
5. `05` — 对照数据命名、混合权威和调试字段
6. `06` — 按已拍板边界和阶段顺序实施稳定化
7. `07` — 在 P0 抖动关闭后接入推箱交互事实与表现状态
8. `99` — 动手前扫一遍未决项
