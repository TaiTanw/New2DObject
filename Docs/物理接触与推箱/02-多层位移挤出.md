# 02 — 多层位移挤出（仅 bias）

> 范围：多层推箱子时的 **位移挤出**；不含实体间速度施力细节（速度见 01 §2.3）。  
> 上级目录：[README.md](./README.md)

---

## 1. 单接触对（AABB）

1. 用双方 **预测 AABB** 求相交矩形。  
2. 取相交矩形 **较短边** 所在轴为挤出轴（水平或竖直）——经典 AABB 最小平移思路。  
3. 按轴比较两物体预测中心，定左右/上下号，得到分离方向。  
4. 权重：`envImpact` 大 → 分到的分离份额大；另一方得 `1 - w`，沿轴反向挤出。

```text
overlap = AABB_A ∩ AABB_B
axis    = (overlap.width < overlap.height) ? X : Y
sign    = 由中心在 axis 上的相对位置决定
w_a     = envImpact_a / (envImpact_a + envImpact_b)
bias_a +=  w_a * depth * dir
bias_b +=  (1-w_a) * depth * (-dir)
```

**不必**对管理器内全部样本做全局排序；pair 内定侧即可。Broadphase / `idA < idB` 去重即可。

---

## 2. 为何不做「挤到全部分离」的递归

```text
改位置 → 新接触 → 再挤 → …
```

- 无上限易抖、卡死  
- 若每步用已挤位置再解下一对（Gauss–Seidel）→ **顺序不同结果不同**  
- 与「T+1 有界传播」哲学冲突  

---

## 3. MVP 算法：N=1 冻快照累加（Jacobi 式）

```text
1. 全员上报预测 AABB（同一 v_pre 快照）
2. 生成当前所有可推接触对（只读该快照）
3. 每个实体 bias = Σ(各 pair 对本实体的贡献)
4. 相位 4 统一：delta = v*dt + bias + …
```

| 性质 | 结论 |
|---|---|
| 遍历 pair 顺序 | 在「只读快照、只累加」下 **基本无关** |
| 同帧整链无残嵌 | **不保证** |
| 多层手感 | 软链、每帧传一跳；可接受 |

硬规则：

1. 禁止无界「分离完才停」  
2. 默认 **N=1**  
3. 残嵌留给下一帧预测  

---

## 4. 玩家 → 箱1 → 箱2 时会发生什么

```text
pair(玩家,箱1)：玩家反向 bias，箱1 顺推方向 bias
pair(箱1,箱2)：箱1 被顶回，箱2 顺推方向 bias

箱1 净 bias ≈ 被推走 − 被前箱顶回
玩家净前进 ≈ v*dt − 反向 bias   → 感到「推不动/变慢」
```

此处「变慢」指 **位移被反向挤出吃掉**，不是本帧改 `v_pre`（与 T+1 速度策略一致）。  
下一帧链仍压缩 → 玩家继续拿到反向 bias → 阻力分帧回传。

---

## 5. 正确性边界

| | 评价 |
|---|---|
| 简便 | 是 |
| 顺序公平 | 是（冻快照累加） |
| 同帧推倒整排且几乎无残嵌 | 否（需以后有限 N 轮增强） |
| 斜向接触 | AABB 轴锁定，可接受于轴对齐推箱 |

增强（非 MVP）：同一相位内对 tentative bias 做有限 N 轮，设 slop；仍禁止无界递归。
