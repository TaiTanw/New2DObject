# 04 — 实体接触：速度算法与数据结构

> 已按现码落地。路径：`PhysicsSolverMgr`、`BasicEntity.PositionPrediction` / `DisplacementCorrection`、`EntitySolutionResult`。
> 上级目录：[README.md](./README.md)

---

## 1. 正式管线

```text
1 GeometricQuery          真实世界感知（静墙 / 地面）
2 PhyFunUpdate            环境 Enter/Exit
3 SpeedCalculation        环境+主动 → v_pre
   PositionPrediction     入账上一帧 secondOrderSpeed → phyH/V
                          清零 result；上报预测 AABB
4 ContactForSolution      AABB 接触对 → 本帧 displacementOffset
                          + ICanMove 则写下帧 secondOrderSpeed
5 DisplacementCorrection  v*dt + 平台 Delta + displacementOffset
                          仅对「非 BasicEntity」静墙整轴裁剪
（SecondOrderPhyFun 已移除：不再对墙/箱边沿 AddForce）
```

`Main.Awake` 调用 `PhysicsSolverMgr.Instance.Init()` 注册相位 4。

## 2. 数据结构

| 符号 | 位置 | 用途 |
|------|------|------|
| `PhysicalBoundingBox` | `Struct.cs` | `point` 预测中心、`size` **半长宽**、`myPhyBox` |
| `projectingArray` | `PhysicsSolverMgr` | 本帧快照；解算后 `Clear` |
| `EntitySolutionResult` | `Struct.cs` / `BasicEntity` | **正式结果**：`displacementOffset` 本帧；`secondOrderSpeed` T+1 |
| `ICanMove` | `CharacterPhysics` | 速度施力门控（箱子未实现 → 只吃 bias） |

`PlayerPhysicsData.displacementBias` / `positionalEmbedding` 为旧草稿，**不走管线**。
`secondaryPressureDic` **已删除**，由 `secondOrderSpeed` 替代。

## 3. 位移挤出（本帧）

```text
v1 = a.point - b.point
v4 = (a.size+b.size) - abs(v1)     // 重叠深度
短轴挤出；weight = envImpact / sum
双方 AccumulateDisplacementOffset，总和分离量 = 重叠深度
```

当前实现为 N=1 冻快照累加。斜坡双箱已证明它只能作为基线；目标是有上限的解算器内迭代，仍禁止无界递归，见 [06](./06-已拍板事务与开工顺序.md)。

---

## 4. 速度施力（T+1）

- 仅 `is ICanMove` 且沿挤出轴朝对方闭合。
- 源速度：`GetPlanarVelocity()`（主动+被动）。玩家走路推箱必须含主动速度。
- 写入对方：`axisSpeed * (receiver.envImpact / sum)` → `secondOrderSpeed`。
- 下一帧 `PositionPrediction` 加到 `phyHSpeed`/`phyVSpeed` 后清零。
- 无长期施力引用；每帧重算。

当前无 `ICanMove` 的箱–箱仍然**只 bias**，这是已确认的接触链断点，将改为相对法向速度语义。

## 5. 静墙

相位 1 检测仍可命中箱子（同 wallLayer），但位移裁剪条件为 `canLeft/RightWall is not BasicEntity`。
可推体重叠不再 `wordDelta.x=0`。
墙滑 `nowWallt` 在位移后 `RefreshWallSlideSnapshot` 刷新（仅 `Wall`）。

当前暂不强制 Kinematic。实体保持 **Dynamic + gravityScale=0**：EPhy 计算期望位移，Unity 2D 暂时负责静态世界的最终非穿透。该模式不是最终定案；切换 Kinematic 前必须补齐静态扫掠、残嵌恢复和接触稳定。

箱体物理根节点冻结旋转，因为现有预测解算只处理平移。视觉 `image` 子节点可独立做装饰旋转，但不能用该旋转表达真实碰撞朝向。

## 6. 新增 API（相对开工前）

| API | 作用 |
|-----|------|
| `BasicEntity.EnvImpact` | 解算器读权重 |
| `BasicEntity.GetPlanarVelocity()` | 闭合/施力源速度 |
| `AccumulateDisplacementOffset` / `AccumulateSecondOrderSpeed` | 接触对累加 |
| `RefreshWallSlideSnapshot()` | 替代旧二阶推墙里的墙滑快照 |
| `PhysicsSolverMgr.TryApplyContactSpeed` | 私有；ICanMove 速度分支 |
| `PhysicsSolverMgr.Init` 由 `Main` 调用 | 注册相位 4 |
| `BasicEntity.DebugSnapshot` | 仅编辑器可用的只读实体快照，不参与解算 |
| `PhysicsSolverMgr.DebugContacts` | 仅编辑器可用的只读接触对快照 |

已移除：`SecondOrderPhyFun`、`NewUpdate`、`secondaryPressureDic`。
