# 03 — 静态墙与预测世界边界

> 结论：静态墙 **不进入** 可推体那套预测 AABB 接触对世界。  
> 上级目录：[README.md](./README.md)

---

## 1. MVP 结论

| | 静态墙 | 可推实体 |
|---|---|---|
| 预测 AABB pair（文档 01/02） | **不进入** | **进入** |
| 主约束 | 当前：相位 1 感知 + Unity Dynamic 最终非穿透；目标：按本帧位移扫掠并裁剪 | 预测重叠 → bias；施力速度可 T+1 |
| 倾斜墙 | Cast / 引擎形状取法线，不塞 AABB | AABB 仅轴对齐运动体 |

取消静墙的预测投射 → 减少计算；撞墙制空仍由相位 1 + 位移约束维持。

---

## 2. 为何墙可以不进预测世界

1. 墙不动：无「双方按 `v_pre` 走」的双边预测问题。  
2. 当前 AABB 不考虑旋转：倾斜墙进预测世界成本高、效果差。  
3. 预测世界的核心价值是 **成对可推挤出**；墙主要是单边防穿，不必进入实体 pair。
4. 撞墙速度制空不依赖接触对管理器。

注意：静墙不进入实体 pair，不等于“距离 0 的帧初探针已经足够”。最终防穿仍需要沿本帧实际位移做 Cast，或在当前阶段由 Dynamic Rigidbody2D 接触解算兜底。

---

## 3. 本帧制空 vs 「位移后确认再制空」

| 策略 | 含义 | 建议 |
|---|---|---|
| 仅位移后（下帧相位 1）确认再制空 | 语义「已贴上」才改速度 | 本帧可能先按满速挤进墙一帧 |
| 本帧用相位 1 贴墙信息或朝向 Cast 裁剪 + 削弱向内速度 | 「将撞 / 正贴」即限制本帧 | **推荐** |

倾斜墙：用 Cast 法线做 **法向裁剪**，不要为墙单独上 AABB 短边算法。

当前采用混合模式：EPhy 产生期望位移，Unity 2D 对静态世界执行最终非穿透约束。待扫掠、残嵌恢复和接触稳定闭环后，再决定是否把静墙最终权威迁回 EPhy。

---

## 4. 两种「权威」分域（非谁取代谁）

| 权威 | 回答的问题 |
|---|---|
| 预测快照（屏障后） | 在这组 `v_pre` 下，可推体之间会怎样挤 |
| 位移后几何（相位 1） | bias/Move 落地后，世界里实际贴着什么 |
| Unity Dynamic 接触（当前过渡） | 将 EPhy 的目标位移投影到静态世界允许的位置 |

- 可推体成对挤出 → 预测权威（本帧 bias）  
- 静墙贴靠 / FSM·AI 感知 → 实位/相位 1 权威  
- 位移后确认 **并不比预测「更真」到可以取消可推预测**；只是静墙换更便宜的权威来源  

混合模式必须观测 `requestedTarget` 与下一物理帧 `actualPosition` 的差值。该差值表示 Unity 对 EPhy 请求施加的最终修正，不能长期作为不可见副作用存在。

---

## 5. 撞墙不要走推箱施力模型

静态墙一般：

- **不**对墙 `AddForce` / `secondaryPressure`  
- **不**建模墙的反作用动力学（除非将来碎墙等）  
- 只约束运动体：法向速度削弱/制空 + 位移不穿  

墙 = 单边约束；箱 = 成对 bias（+ 可选 T+1 力）。二者不要揉进同一套「实体间施力」。

