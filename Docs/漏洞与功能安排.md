## 二、具体描述

### V_1（旧 U17）持续推箱抖动

接触候选仍要求预测 AABB 实际重叠；动态力 link 另受闭合速度控制；Dynamic 刚体仍可能二次修正。P0 先取证，不先调小 slop。旧 U14（skin / slop / 接触保持）并入本问题的 `0.2`，不另开功能号。

### V_2（旧 U16）墙顶边缘起跳停顿

`wall (2)` 在 Layer 7；地面/墙检测掩码均含 6+7，`distance=0` 时分类可能切换。先记录原始命中，不改跳跃速度掩盖。

### V_3（旧 U15）静墙裁剪与实体 pair

静墙不进预测 AABB pair（见 `Z_6`）。墙后裁剪与实体偏置的反馈仍待设计。

### V_4（旧 U18）阻塞推动

需要方向约束或 appliedDelta 一类结果接口，才能判断「推了但没推动」。

### F_1（旧 U6）推箱表现

策略已拍板：公开接触事实，由表现层解析推动接触 / 有效推动 / 阻塞推动。P0 关闭前不接正式推箱动画。

### F_2（旧 U4、U11）多箱链

`ICanMove` 门控已移除，有向动态力已用；同帧链式约束未闭环。N=1 不是终态。

### F_3（旧 U13）全 Kinematic

混合 Dynamic 仍是当前稳定模式。未完成静态扫掠与残嵌恢复前不切换。

### F_4（旧 U1）闭合速度阈值分档

水平相对闭合已落地，分档未定标，跟 P0 实测走。

### F_5 第一阶段

- `0.1` 运动快照：预测与提交共用 `plannedWorldDelta`，见 `08`。代码已提交；Play Mode 仍待验。
- `0.2` 环境接入：能力接口与登记关系，见 `09`。这是此次开工专述；未提交代码不写入框架总览。
