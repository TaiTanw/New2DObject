# 整体语义调整

本清单用于**不新增功能的人工核对与整理**：核对现有行为、字段含义及计算职责，记录开发者确认的取舍。过程中可以修复漏洞，但不将功能扩展混入整理事项。

编号使用 `K001`、`K002`……，与[历史待办](历史待办.md)中的 `K_1` 等旧编号分开；历史事项不自动转入。每项简述结论，发现、询问与确认过程统一收入[开发日志](开发日志.md)。
