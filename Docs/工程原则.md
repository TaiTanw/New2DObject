# 工程原则

当前分层与实现边界。任务优先级看[待办安排](待办安排.md)，代码入口看[项目 README](../README.md)，历史取舍看[历史回顾](历史回顾.md)。

## 八条原则

1. **逻辑与宿主分开。** 宿主负责组装、调度、生命周期与场景引用；玩法规则尽量用普通类型表达。当前仍有 Unity 类型依赖，不宣称已完全引擎无关，也不提前建设万能适配层。
2. **单向管线。** 输入 → 实际类别 → 行为策略 → 执行 → 表现。下层不回写上层内部状态，跨层通过明确接口和只读数据。
3. **行为与执行分开。** 行为决定能否做、做什么；执行计算速度、位移和其它效果。FSM 不写 Rigidbody2D、不积分重力。
4. **感知与职能分开。** 几何只描述命中；环境能力解释效果。无脚本表面仍可阻挡，有几何接触不等于可墙滑。
5. **环境关系归实体。** EntityEnvironmentContext 核对来源并登记/撤销效果；源端 Registration 只保留身份与清理反向索引，不持有实体累计速度。
6. **按能力扩展。** 新效果优先接入窄接口，避免修改底层查询和全局时序；同层复杂组织不堆进一个总控类。
7. **角色四层组装。** 实际类别 Player 负责初始化和输入接入；PlayerStateMachine 负责行为；CharacterPhysics / BasicEntity 负责执行；PresentationLayer 只读输出。公共输入与调度不算第五层。
8. **配置外置。** 探测层、尺寸、开关等走配置资产；本阶段的算法常量须在后续定标时明确归属，不为改名同时迁移序列化数据。

## 当前边界

- 场景环境发现仍要求 Collider 同物体的唯一 BasicPhysicalObject；FindHost 对外返回 IEnvironmentSource。接口返回类型不等于可以发现任意纯 C# 来源。
- 脚下采样地面响应/平台位移，并按现规则登记持续效果；区域只登记持续效果；侧面只解析墙滑。
- 接触查询排除 Trigger，区域事实只收 Trigger；不通过改全局查询开关影响其它模块。
- 无三类持续能力不建立 Binding；接口值为零仍是能力存在。表面采样不依赖 Binding。
- 角色与箱子使用 Dynamic 刚体，由 Unity 统一模拟处理实体接触；箱体物理根节点冻结旋转，表现子节点的装饰旋转不改变实际碰撞。
- 静墙、可爬坡面和头顶在写入速度前按几何收一次；任意箱链、多箱上坡后置，后续调整须明确时序与回归依据。

## 时序与数据

`Physics2D.simulationMode` 为 Script，MonoPublicMgr 按 0→5 调度，相位 0 后同步几何、相位 4 后统一模拟一次：

| 相位 | 当前职责 |
|---|---|
| 0 | 平台运动产生 Delta、水更新范围与水位，同步几何 |
| 1 | 读取上一步原生接触；探针、单向平台与区域查询 |
| 2 | 环境来源核对、脚下／水事实、墙能力解析 |
| 3 | 合成本步速度，按静墙、可爬坡面和头顶收一次后写入刚体 |
| 4 | 驱动者先写第一只侧面箱子的水平速度，再推进一次 Unity 物理模拟 |
| 5 | 回读实际位置与速度，供下一步和表现读取 |

命令与模拟结果分开；自动模拟关闭，不重复推进物理，不另设提交队列。原生接触在相位 1 主动查询，来自上一步完成的模拟；跳跃、墙滑／墙跳仍归规则，不改由碰撞生命周期回调决定。

| 数据 | 归属与用途 |
|---|---|
| Rigidbody2D、PlayerPhysicsData | 刚体实际速度为唯一跨帧运动基准；动作参数不继续累计已被碰撞改变的旧竖直速度 |
| EntityEffectState | 环境与限时命令参数的唯一持有者，不保留接触传力或来源尾效，不管理来源 Binding |
| GeometryPhysicsData | 本帧几何事实；isGrounded、onLeftWall/onRightWall 不代表表面能力 |
| PhysicalFunctionData | 角色相位 2 解析的左右墙滑能力；逻辑只读可用性，执行读取参数 |
| EntityEnvironmentFrame、EntityWaterFrame | 本步表面／水事实；不拥有累计速度或泳姿，游泳模式由 Player 按水事实选择 |
| EnvironmentParameter | 环境槽参数与计算点；默认/当前两套槽经 BasicPhysicalObject 校验、提交与恢复 |

表现从相位 5 回读的实际运动推导状态，不以动画需求定义物理字段。

## 调试与回归

- 观测数据只能由运行逻辑复制，不能参与解算或回写速度、位置和登记关系。
- 仅编辑器观测的声明、赋值与专用计算放在 `#if UNITY_EDITOR` 内；混在运行时类型中的观测字段用 `debug` 前缀，公开入口用 `Debug`，注释标 `[EditorOnly]`。专用 Debug 快照内部字段无需重复前缀。
- 正式计算即使结果也用于显示，仍属运行逻辑，不能被移入编辑器宏。
- 用 fixedTick 对照本步运动命令与相位 5 模拟结果；不每帧大量打印日志。
- 回归区分编译、Edit Mode 集成和 Play Mode 场景验收，不互相替代。当前角色/箱体均启用插值作为用户确认的显示基线；不要用显示平滑反推物理解算正确。
