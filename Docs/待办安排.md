## 下一步大致方向

**F8 已完成**，下一主线回到 F6 的运动建模评估与实现。

1. **先整理数据归属，再统一运动语义（F6）。** `F_6.1` 只收束实体效果容器与窄口，保持现有行为；随后以二维速度和位移表达运动，区分自由运动、地面切向运动、法向约束及平台携带。重点重新评估着地时未计入 `phyVSpeed` 的规则，以及原始速度与斜坡后实际位移的不一致。
2. **再处理箱链与静态约束（F2 + V3/V4）。** 从沿 X 轴传递速度转向按接触法向判断相对运动；让斜坡支撑、前方阻挡与多个箱子的运动相互协调。有限迭代是候选，仅增加次数不能替代正确的运动约束。
3. **以平地单箱 → 平地多箱 → 斜坡双箱/多箱 → 末箱抵墙检验方向。** 保持插值配置，分别观察物理结果与显示效果；V2 复测可一并进行。

这是评估方向；`F_6.1` 固定数据归属与迁移边界，不预定新增类的名称，也不冻结解算器方案、迭代次数或未来速度回写时序。当前 T+1 施力、N=1 和静墙后裁剪是需评估的现状，不是新模型必须永久保留的限制。
