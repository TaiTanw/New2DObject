## F_6.2 预估：真正统一水平、竖直速度

先拆清**速度计算步骤**，再改二维运算和本帧快照。目标是让一帧中的来源、事件、重力/支撑、位移各有明确输入与输出，不再以“水平完成后再竖直完成”组织计算。这是下一单元的评估范围，尚未批准公式或开工实现。

| 候选步骤 | 本帧应明确的输入与输出 | 现码对应位置 |
|---|---|---|
| 1. 取本帧依据 | 几何支撑法线、重力方向、脚下参数和平台 Delta；确定输入基准方向 | 相位 1/2 的 `GeometryPhysicsData`、`EntityEnvironmentFrame` |
| 2. 更新效果数值 | 汇总移速修饰、持续/限时速度和动态力的跨帧积分；说明每类速度属于世界方向还是局部切向 | `EntityEffectState.UpdateMovementModifier / UpdatePassiveSpeed` |
| 3. 消费角色动作 | 根据输入方向生成主动速度；跳跃、松跳、墙跳只修改其应负责的运动状态，明确同帧事件优先顺序 | `BasePhysicsEntity.HActiveSpeedOperation → CharacterPhysics.PhyEventUpdate` |
| 4. 更新自由运动 | 在同一个二维速度状态中施加重力、墙滑等规则，得到尚未经过支撑约束的自由速度；明确事件与重力的先后 | `VUnderForce → VActiveSpeedOperation`、`GetPlanarVelocity` |
| 5. 处理支撑并形成位移 | 按支撑法线处理切向/法向速度；平台携带单列，得到本帧期望世界位移，供预测与提交共用 | `BuildMotionFrame → EntityMotionFrame` |

现码的逐步计算可写为：效果更新得到 `phyHSpeed/phyVSpeed`；输入得到 `horizontalSpeed = onMove · speed · (1 + nowPhyNum)`，随后事件可改写 `verticalSpeed`；空中再执行 `verticalSpeed += gravity · fixedDeltaTime`，着地则把负的 `verticalSpeed` 归零，最后墙滑可限制其下落值。此时 `GetPlanarVelocity = (horizontalSpeed + phyHSpeed, verticalSpeed + phyVSpeed)`。空中直接用该向量乘 `fixedDeltaTime`；着地却改用 `verticalSpeed · fixedDeltaTime` 加上“总 X 速度大小 × 地面单位切线”，因此 `phyVSpeed` 在着地位移中丢失。F6.2 要拆开的正是这些**来源更新、事件消费、重力积分、支撑处理和位移积分**，不是只合并最终两个数。

步骤 2–4 的先后是待核对的运算顺序，不等于照搬现有调用顺序。跨帧累计状态与本帧合成速度需区分；本轮不预设将 `PlayerPhysicsData` 标量立即删除。相位 4 的接触力仍可能从下一帧生效；改变这一点需与 F2、V3/V4 一起评估。

### 已提出的方向约定

用户对输入速度方向的初步约定：**着地时沿脚下法线的垂线，空中时沿当前重力方向的垂线**，为将来的可变重力留出方向定义。按当前默认重力向下理解，左输入对应“支撑法线向左旋转 90°”；空中可先取重力反向作为参考法线，再向左旋转 90°。右输入取反方向。这里定义的是**主动输入速度的方向**，尚未决定外部状态速度、限时速度、动态力是否也随该基准旋转。

候选二维计算的暂定记法：输入轴 `s∈[-1,1]`、主动速率 `m`、单位参考法线 `n`，取右切线 `t=(n.y,-n.x)`，则主动输入速度 `v_input=s·m·t`；着地取 `n=normalize(groundNormal)`，空中取 `n=-normalize(gravityDirection)`。`m` 如何包含移速修饰、以及未来重力为零或方向突变时如何维持参考方向，均待确定。取得合成自由速度后，先按支撑规则生成自身运动速度 `v_motion`，再以 `v_motion·fixedDeltaTime + platformDelta` 形成期望位移；支撑规则尚未确定，因此这不是已批准的最终公式。

### 仍需在 F_6.2 开工前收敛

- 着地时法向速度如何处理：向内的重力/外力、向外的环境速度和跳跃首帧分别何时保留、何时离地；不能直接沿用“丢弃 `phyVSpeed`”，也不能无条件加回。
- `EntityEffectState` 中持续速度已有世界 `Vector2`；限时速度、动态力当前只有 X 累计。要逐类确认方向与累计坐标，避免把世界速度误旋转为坡面切向速度。
- 事件、重力积分、墙滑限制与支撑处理的精确先后；尤其同一物理帧内跳跃和松跳的消费结果。
- `EntityMotionFrame` 要向后续接触判断暴露哪些**正式运行数据**，使接触读取与预测位移同义；不以编辑器观测副本代替解算输入。

F6.2 的最小验收先看单体：平地/坡面左右输入、空中运动、向上/向下外部速度、起跳首帧和移动平台，核对预测位移与请求位移。平地多箱、坡面箱链及末箱抵墙是后续 F2、V3/V4 联合验收，不因本单元通过而视为完成。
